# Repository handoffs

When working on card-play animations or battle-board visual effects, read and follow [`ArtBrief/VFX/CLAUDE-VFX-IMPLEMENTATION.md`](ArtBrief/VFX/CLAUDE-VFX-IMPLEMENTATION.md) first. It contains the full 161-card effect map, the 49 source atlas names and categories, the runtime wiring already in place, attribution requirements, and the Unity review checklist. Do not call the VFX work complete until the source atlases have been imported and the listed Unity review is finished.

For card illustration work, also follow [`ArtBrief/CLAUDE-CARD-ART-HANDOFF.md`](ArtBrief/CLAUDE-CARD-ART-HANDOFF.md).
